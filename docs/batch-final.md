## 1. イベントの整備

今のイベントは 戦闘 / 強敵 / 宝 / 泉 / 何も無い / 加入 の 6 種だけで、
道中がボス部屋まで一本道になっている。次を足す。

### 種類を増やす (5 種を新設)

| イベント | 重み | 内容 |
| --- | --- | --- |
| 隊商 | 8 | 行商人。金を払って回復薬を 1 個買える (道具屋より高い) |
| 祠 | 8 | 古い祠。二択で「祈る (経験値)」か「壊す (金)」 |
| 落石 | 8 | 崩れた通路。二択で「押し通る (HP を払って先へ)」か「迂回する (何も無し)」 |
| 死体 | 8 | 冒険者の亡骸。装備を漁ると金。**罠が隠れている (25%)** |
| 休息 | 8 | 安全な窪み。二択で「休む (HP 回復)」か「先を急ぐ (経験値)」 |

- 数値 (回復量・金額・経験値・HP の代償) は既存のイベントの水準に合わせて素直に決めてよい。
  **細かい調整はしない**
- 罠は引き続き単独のイベントにしない。宝箱・何も無い・死体の結果に隠す

### 分岐を増やす

- 上の新規イベントのうち 祠 / 落石 / 休息 は**常に二択**にする。
  これらは「選ばせるためのイベント」なので、2 割の抽選には乗せない
- 既存のイベント (宝箱など) の二択は今までどおり 2 割の抽選のまま

## 2. PWA

`pocket-rogue` の `public/` を参考にする (同じ作りでよい)。

- `public/manifest.webmanifest` — 名前 `Pocket Legion`、`display: standalone`、
  背景と테마色は `style.css` の `--bg` に合わせる
- `public/sw.js` — ビルド成果物をキャッシュし、オフラインで起動できるようにする。
  **更新が届かなくなる作りは避ける** (新しい版があれば取りに行き、
  無ければキャッシュを使う形にする)
- `public/icon-192.png` / `icon-512.png` — 単色の背景に文字を置いた素朴なもので構わない。
  生成スクリプト (`scripts/make-icons.mjs`) を置いてもよい
- `index.html` に manifest と theme-color を足し、`main.ts` で Service Worker を登録する
