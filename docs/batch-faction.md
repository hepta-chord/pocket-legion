# 陣営倍率の実装メモ

ルールは `plan.md` の「ステータスと陣営倍率」「前衛の同陣営補正」が正。
ここは型と関数の割り当てだけを書く。実装が済んだらこのファイルは消す。

## 1. 所持ベースの陣営倍率

- `src/roster.ts` (新設) に `factionMultiplier(owned, faction)` を置く
- 計算: `1 + (同陣営の他キャラの実効攻撃力 + 実効体力 の合算) / 3000`、
  **上限 2.0**。実効値は `growth.ts` のレベル込みの値を使う
- 「自分以外」なので、キャラごとに合算元が 1 人ぶん違う。
  人数が多いときに毎回全走査すると重いなら、陣営ごとの合計を先に出して
  自分のぶんを引く形にしてよい
- 出撃時に `Fighter` を組むところ (`run.ts` / `formation.ts`) で倍率を掛け、
  `Fighter.attack` / `vitality` を実効値にする。
  戦闘中に倍率が変わることは無いので、戦闘の途中で計算し直さない

## 2. 前衛の同陣営補正

- 前衛 6 人のうち同陣営が n 人 (n >= 2) いると、その陣営のキャラは
  全ステータス + (n - 1) * 5%
- 前衛の顔ぶれで決まるので、**戦闘開始時とダウン・交代で前衛が変わったときに
  計算し直す**。`battle.ts` の中で扱うのが素直
- 所持ベースの倍率とは別に掛ける (掛け算で重ねる)

## 3. 表示

- 編成画面と拠点のキャラ枠に出す攻撃力は、**倍率を掛けた実効値**にする。
  素の値を見せても編成の判断に使えない
- 編成画面に陣営倍率そのものを出す (例: `王国 x1.32`)。
  何を集めると何が伸びるかが見えないと、集める動機が生まれない
- 前衛の同陣営補正も、編成画面で今の前衛に対する値が見えるとよい

## 4. sim

- `assumedLevel` で振ったレベルに加えて、**所持人数も振れるようにする**。
  倍率は所持で決まるので、「レベルだけ高くて仲間が少ない」状態しか測れないと
  中盤以降の実態と合わない。区画ごとに想定の所持人数を置く
  (浅層 5 人、中層 12 人、深層 20 人くらいを初期値に)

## 5. 数値

**実装では触らない。** 定数 3000、上限 2.0、前衛補正 5% は初期値として置くだけにして、
`npm run balance` を見ながらの調整は計画側がまとめて行う。
