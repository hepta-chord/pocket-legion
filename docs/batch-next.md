# 次のバッチの実装メモ

ルールは `plan.md` が正。ここは割り当てだけを書く。済んだらこのファイルは消す。

## 1. 敵のバフを画面に出す (不具合)

敵の鼓舞・防御 (ward) は `battle.ts` で計算に入っているのに、`BattleView` の敵側に
出ていない。ログに「身を固めた」と出るだけで、今どれだけ固まっているかが見えない。
「効果が出ていない」ように見える原因になっている。

- `BattleView.enemy` に `cheerStacks` / `cheerTurns` / `wardStacks` / `wardTurns` を足す
- 敵の状態アイコン列に、味方と同じ形で出す (`鼓舞 ●●○ 2` のような)

## 2. ボスの鼓舞・防御の頻度を下げる

今のボスの通常行動パターンは `[attack, cheer, ward]` で、そこから 2 回引く。
**大半のターンが自己強化になり、殴ってこない。**

- パターンを重み付きにする。`[attack, attack, attack, cheer, ward]` を初期値とし、
  攻撃が 6 割、鼓舞と防御が 2 割ずつになるようにする
- 既に 3 枚積んでいる (上限) 系統は候補から外す。上限で無駄撃ちしない

## 3. カクサン (3 人目の固定キャラ) とバフ剥がし

- `data/characters.ts` の固定キャラの名前を変える:
  主人公 `hero` → **コーモン**、相棒 `mate` → **スケサン**
- **カクサン** (`aide2`) を足す。傭兵団・レア扱い・所持から外れない。
  スキルは**バフ剥がし**と**ガード 1** (ward1)。攻撃力と体力はコモンの壁役と同程度でよい
- 初期所持は コーモン / スケサン / カクサン の 3 人になる

**バフ剥がし** (`SkillEffect` に `{ kind: 'dispel' }` を足す):

- 対象の鼓舞と防御 (ward) のスタックを 0 にする。1 回で全部剥がす
- **味方と敵の双方に効く手段**にする。味方が使えば敵のバフを剥がし、
  敵が使えば味方のバフを剥がす。敵側の行動パターンにも `dispel` を混ぜられるようにする
  (今回は敵に持たせなくてよいが、型としては扱えるようにしておく)
- コストは物理と同じ扱い (ターン内 +1 で頭打ち) の 1 コストを初期値にする

## 4. レアの名前

レア 4 人に所属陣営の題材に沿った固定名を付ける (カタカナ)。

- 王国 = 天気 (英語) / 教団 = 果物 (イタリア語) / 傭兵団 = 酒 / 辺境 = 山 (日本語)
- コモンの候補と重ならない名前を選ぶこと

## 5. 攻撃力の表示

探索画面のキャラ枠に、**陣営倍率と前衛補正を掛けた最終値**の攻撃力を出す。
既に編成・拠点では出ているはずなので、探索画面で欠けていれば揃える。

**実装では触らない。** 上のパターンの重み、バフ剥がしのコスト、カクサンの数値は
初期値を置くだけにして、調整は計画側がまとめて行う。
